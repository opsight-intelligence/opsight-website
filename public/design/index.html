Colour

Brand, lines, severity

The navy is the anchor. Each intelligence line has one accent, used only for its badge and its chart series — never for text. Severity colours are reserved and always ship with a mark and a label, never colour alone. The three line accents pass every colour-vision gate as a set in both themes; procurement's aqua is below 3:1 on the light ground, so a mark in it is always labelled.
